# 일본어 기초 전체 교재

일회성 사용자 요청(2026-11-02)에 따라 문자·발음부터 생활 문법, 짧은 읽기·듣기와 종합 복습까지 묶은 독창적 한국어 교재입니다. 기존 날짜별 일본어 001–030을 대체하거나 사용자가 공부를 마쳤다고 간주하지 않습니다.

## 구조

- `course.json`: 출판일, 범위 및 사용 안내.
- `units/jf-01.json`–`jf-30.json`: 안정적인 장 ID와 본문.
- 01–02 문자·발음, 03–12 문장 기초, 13–20 동사 활용, 21–26 생활 표현, 27–29 읽기·듣기, 30 누적 복습.
- 장마다 목표, 설명, 예문, 회화, 단어, 연습과 풀이, TTS 듣기 대본·질문, 자기 점검, 출처.
- 단어·문장에는 일본어, 가나 읽기, 한국어식 근사 발음, 한국어 뜻, 로마자, 원문 TTS를 함께 기록.

## 학습 범위와 한계

N5 입문 수준의 주요 기초를 연결하고 일부 유용한 초급 확장을 포함합니다. JLPT가 공식 개별 문법·단어 목록을 공개하지 않으므로 '공식 N5 전체 목록'이라고 부르지 않으며 합격이나 학습자 습득을 보장하지 않습니다. 각 장 출처는 문법 확인용이며 예문과 연습을 복제한 출처가 아닙니다. 18장의 의무 표현과 26장의 경험·활동 열거 등은 기초를 넓히는 확장으로 표시합니다.

TTS는 기기 합성 음성이며 사람의 녹음·실제 시험 음원과 다릅니다. 한국어식 발음으로 일본어의 길이·억양·조음이 완전히 표현되지 않습니다. 듣기에서는 먼저 대본을 숨긴 채 요점을 듣고 이후 대본과 근거를 확인합니다.

## 보존과 검증

기존 레슨, 날짜, URL, 출처, 학습 체크·복습 ID는 변경하지 않습니다. 새 체크는 기존 동기화 객체 안에서 `japanese-foundation:jf-XX:<section>`을 사용합니다. 기존 단어 노트와 이 교재의 단어 모음은 출처와 범위를 구분합니다.

빌드 스키마는 30장 순서·ID·선행학습·복습 참조·필수 본문·TTS 원문 일치를 검사합니다. 기본 문자 92개, 원본 60개 SHA-256 보존, 소스 출처, 저장 키, 직접 접속, 검색·필터, 접힌 답과 듣기 대본, 원문 일본어 TTS 호출을 테스트합니다. 화면과 실제 기기 음성의 품질은 별도 검증 항목입니다.
