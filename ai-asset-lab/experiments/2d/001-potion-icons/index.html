판타지 포션 아이콘 4종

AI 이미지 생성 → 128×128 투명 PNG 분리 → 게임 UI 크기 검토. 실제 제작 결과와 검증된 항목, 실패·미검증 사항을 함께 기록합니다.

⚠️ PARTIAL · 부분 완료🎨 2D / UI 아이콘🧭 다음 실험은 사용자 결정

01 · 실제 결과물

AI 첫 번째 합성 이미지에서 추출한 네 아이콘의 웹 최적화 PNG입니다. 공개본은 원본 RGBA PNG를 64색 인덱스 팔레트와 투명도(tRNS)로 변환한 시각적 파생 파일이며, 최초 검증한 원본 PNG와 바이트 단위로 동일하지 않습니다.

02 · 64px UI 적용 미리보기

실제 64px 렌더링 크기로 밝고 어두운 배경에 배치한 브라우저 미리보기입니다. 사람이 평가하는 가독성 실험의 대체물은 아닙니다.

03 · 실험 과정과 설계 이탈

원래 실험 가설은 아직 검증하지 못했습니다.

승인 설계는 아이콘별 1회씩 총 4회 독립 생성이었으나, 실제 요청 2회 모두 아이콘 4개를 한 화면에 합성했습니다. 이를 별도 생성 4회로 간주하지 않습니다.

생성 01수평 4종 스트립

2172×724 RGBA. 실제 투명 배경이 있으므로 최종 분리용으로 사용했습니다.

생성 022×2 아이콘 그리드

1422×1106 RGB. 체크무늬가 픽셀로 포함된 불투명 이미지여서 최종 자산에서 제외했습니다.

후처리4종 파일 분리

각 포션 영역 잘라내기, 알파 경계 검출, LANCZOS 리사이즈, 중앙 정렬을 적용했습니다.
