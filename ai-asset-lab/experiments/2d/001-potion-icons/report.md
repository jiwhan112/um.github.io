- 생성 도구: ChatGPT 이미지 생성 (실제 내부 모델 버전·시드는 확인되지 않음)

## 원래 가설과 실행 차이

**원래 설계:** 포션 4종을 서로 독립된 이미지 생성 요청 4회로 만들고 스타일 일관성을 평가한다.

**실제 수행:** 이미지 생성 요청은 총 2회였으며, 양쪽 모두 하나의 이미지에 포션 4개가 합성된 결과였다. 첫 이미지는 2172×724 RGBA 수평 스트립, 두 번째 이미지는 1422×1106 RGB 2×2 격자였다. 두 번째 체크무늬 배경은 실제 알파가 아닌 픽셀이므로 최종 아이콘 제작에 사용하지 않았다.

## 제작 결과

- 첫 RGBA 출력 한 장을 4개 구역으로 나눈 뒤 알파 임곗값(8 초과) 기준 경계를 찾고 외곽에 3px를 더했다.
- 각 구역을 비율 유지하면서 최대 104px로 LANCZOS 축소해 중앙에 배치하였다.
- 원본 완성 자산: 체력/마나/해독/비전, 각 128×128 **RGBA PNG**.
- 원본 자산의 외곽 여백: P01 24/12/25/12, P02 24/12/25/12, P03 24/12/25/12, P04 24/12/25/12 (좌/상/우/하 픽셀).
- 웹 공개본은 각 원본의 컬러를 64색 인덱스 팔레트로 최적화한 별도 PNG입니다. 알파는 tRNS로 보존되지만 파일의 비트 구조/색상값/해시는 원본과 달라 별도 관리합니다.

## 주의사항

**첫 합성 이미지 한 장에서 분리한 네 아이콘**이라는 점을 연구 주가설의 성공으로 표현하지 않습니다. 게임 UI 시제품 용도로는 유용하지만 독립 생성 반복성은 별도 설계와 검증이 필요합니다.

이번 GitHub 게시에는 공개 최적화 PNG 4개와 실험 문서가 포함됩니다. 최초 이미지 두 장 및 정확한 RGBA 원본 4종의 바이너리는 이번 커밋에 포함되지 않습니다. 원본 SHA-256은 `evaluation.json`에서 확인할 수 있습니다.
