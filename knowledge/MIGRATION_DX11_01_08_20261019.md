## 검증된 것과 검증되지 않은 것

- GitHub 새 Linux 빌드: 01~04 CPU 프로젝트 각 1개, 05~08 묶음 4개, 총 **8개 프로그램**을 GCC C++20, GCC C++11, Clang C++20 ASan/UBSan 환경마다 반복 실행하는 CI 구성을 마련했습니다. 실제 결과는 CI 링크와 원시 로그를 확인하여 별도 집계합니다.
- 원래 01A 네이티브 C++/CMake는 3개 완전 파일로 보존. DX11 01 본문에서 참조한 Notion 파일 첨부 `dx11_init01_full_sources.md`는 서명 URL 조회에 성공했으나 **원본 첨부 바이너리의 다운로드·SHA-256 대조는 아직 완료되지 않았습니다**.
- Win32 초기화/삼각형/텍스처, HLSL 예제는 **Windows/MSVC·D3D11/GPU/FXC/DXC 실기기에서 컴파일·실행하지 않았습니다**.
- Mermaid·LaTeX는 원문과 화면상 코드 블록으로 보존했습니다. 시각적으로 실행되는 인터랙티브 다이어그램이라고 표시하지 않습니다.
- 09~18 원본·하위 소스·이미지 검증은 **다음 배치**입니다.
- Notion 원본, 기존 브리핑/언어/사고력, Supabase 설정 및 다른 예약 작업은 미수정.
