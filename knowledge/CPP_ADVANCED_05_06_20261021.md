## 본문과 화면 검사

두 단원은 개념과 원리 / 실습·복습 / 출처·검증 / 원문·변경기록의 4탭을 따른다. SVG 6개, 렌더링되는 Mermaid 3개, 비교표, 접힌 복습 22문항과 한국어 전체 소스를 연결한다. 코드 원문이 도식 대신 그대로 표시되지 않는지, 한글 캡션·확대·접힌 원문·전체 소스·탭·이전 다음 문서가 PC와 모바일에서 동작하는지 검사한다.

05는 저장 방식·무효화·알고리즘 전제를 연결한다. `rehash(100)`의 100을 정확한 버킷 수로 단정하지 않는다. 원소를 지운 뒤 반환된 반복자 사용, 재해시의 반복자와 원소 포인터 차이, 비교자 표본의 한계, `clear()`의 크기·용량·소유 대상 수명을 나눈다.

06은 선언·정의와 객체·저장 공간의 경계를 설명한다. 원본 `Pool`은 전역 할당·해제를 세는 교육용 코드이며 재사용 풀이나 일반적인 확장 정렬 allocator가 아니다. PMR 실패는 1,024바이트 arena와 null upstream에 4,096바이트를 요청해 재현한다. 실제 시스템 OOM이나 성능 측정이 아니다. Pimpl의 새 구현 준비 후 swap 구조와 실제 6회 검사를 구분하며, 할당 실패 주입·ABI·재빌드 시간 검증을 주장하지 않는다.

로컬에서 스키마·TypeScript·저장소 규칙·게시 계약·단위 30개 검사를 통과했다. Vite 빌드와 게시 산출물 검사도 통과했다. 전체 사이트112문서·언어36강의·기사200개 및 직접 진입158경로와 내부 링크를 확인했다.
