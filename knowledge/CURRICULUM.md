# ATLAS NOTE — 프로그래밍 학습 목차·집필 설계 v3

수정일: 2026-10-21
상태: **상위 목차 유지 · C++ 기초부터 시각 교재 구성**

## 현재 작업 범위

- 2026-10-19에는 상위 목차를 정했다. 이후 원본 이관 및 시각 교재 개편을 진행했고, 사용자가 승인한 DX9 09 형식을 기준으로 **C++ 기초부터 원래 단원 순서대로 진행**한다.
- 개념 그림·렌더링되는 Mermaid·짧은 설명 예제·한국어 주석 전체 코드·접힌 복습 답안을 함께 제공한다. 조작 실습은 개념을 직접 비교할 수 있을 때 사용한다.
- Notion 원문과 첨부 소스는 별도 보존한다. 새 설명·그림·주석은 파생 교재임을 구분하고, 원본 무결성과 현재 코드 실행 결과를 각각 검증한다.
- 이미 발행된 DX11 Frustum, 알고리즘 LIS, Python BeautifulSoup의 파일·경로·출처와 다른 공개 교재를 유지한다. 초기 시범 교재 3개는 전체 공개 문서 수를 뜻하지 않는다.
- 아래 목록 중 아직 본문이 없는 항목은 **사이트맵의 비활성 목차**일 뿐이다. 빈 교재/샘플 코드/가짜 완료 항목을 생성하지 않는다.
- Modern C++과 새 엔진·Python 교재는 별도 과정이다. 집필 범위가 확정되기 전에는 문서 개수나 출판 일정을 임의로 정하지 않는다.
- 완료 상태는 코드·학습 본문·출처·검증 기록과 라이브 페이지를 모두 확인한 뒤에만 표시한다.

## 확정한 상위 사이트맵과 목차 순서

1. **C / C++**
   1. C 언어
   2. C++ 기초·심화
   3. Modern C++ — C++11 이후 버전별 언어 및 표준 라이브러리 변화. 실제 작성 시 최신 표준의 **확정/진행 중 상태를 구별**한다.
   4. Effective C++ — 기존 책의 원칙과 코드의 전제 및 시대적 한계를 구별한다.
   5. Effective Modern C++ — Scott Meyers의 『Effective Modern C++』을 별도 심화 트랙으로 다룬다. 책 내용을 대량 복사하지 않고 독립 설명·예제로 학습한다.
2. **Windows·그래픽스 프로그래밍** (Windows SDK·WinAPI·DirectX 기반 프로그래밍을 포괄하는 이름)
   1. WinAPI
   2. 게임 수학
   3. DirectX 9
   4. DirectX 11
   5. DirectX 12 — **신규 집필 예정**, 기존 Notion 이관 실적으로 집계하지 않음
3. **그래픽스 기술**
   - 프레임워크/엔진 기능 구현에 집중하는 2번 항목과 구분해 **알고리즘·기법의 원리·제약·실험**에 집중한다.
   - 후보: 셰이더, 그림자, Navigation Mesh, IK. 세부 주제 분리와 순서는 **작성 시 재계획**한다.
4. **컴퓨터 과학**
   - 컴퓨터 구조, 운영체제, 네트워크. 이번 피드백에서 분류 변경 요청이 없어 기존 분류를 유지한다.
5. **자료구조 / 알고리즘**
   - 세부 순서·교재 범위·문제풀이 분류는 **작성 시 다시 계획**한다. 기존 공개 LIS 시범 교재는 별도 참고 자료로 남긴다.
6. **게임 엔진 개발**
   - 기존 Notion의 디자인 패턴/Unity 노트를 이관하는 과정으로 취급하지 않는다.
   - 새 엔진 파츠·시스템 개발 학습으로 **독립 집필**하며 세부 과정은 집필 전 확정한다.
7. **Python·개발 도구**
   - 기존 Notion의 Python/자동화 노트를 이관하는 과정으로 취급하지 않는다.
   - Python 학습·개발 도구·자동화를 대상으로 **새 교재를 집필**한다. 기존 BeautifulSoup 시범 교재는 참고용으로만 보존한다.

## 사이트맵 상태 표시 규칙

| 표시 | 뜻 |
| --- | --- |
| 기존 자료 기준 | 이미 존재하는 학습 분류를 참고하는 목차. 이전/개정 완료를 의미하지 않음 |
| 신규 집필 예정 | Notion 이관이 아닌 새로운 교재로 앞으로 작성 |
| 집필 시 설계 | 하위 과정과 순서를 사용자 피드백을 받아 나중에 확정 |
| 기존 구성 유지 | 이번 수정의 대상이 아닌 상위 분류 |
| N개 공개 | 실제 페이지 경로가 존재해 즉시 열 수 있는 교재 수 |

공개 문서 수는 `knowledge/data/catalog.json`과 실제 배포 색인에서 확인한다. 단원 본문과 별도 전체 소스 문서를 구분하며, 미집필 목차를 문서 수에 넣지 않는다. 초기 시범 교재도 기존 URL로 접근할 수 있다.

기준: [Notion C++ 기초문법 개정판](https://app.notion.com/p/2275f5f2c81a404e9c908dc0296ed65e), [C++ 기초 → 심화 과정](https://app.notion.com/p/580e48caa0f642d9b6d077fbe7509d4f). 원본을 읽기 전용으로 대조했으며, 현재 학습 기준은 C++20이다.

01~03은 이번 배치의 **교재 3개**다. 공통 첨부에는 04~05의 예제까지 들어 있으므로 [공통 실습 팩](./shared/cpp-basics-lab/README.md)의 원본 6개 정상 프로그램을 함께 복원한다. 소스가 보존·실행되었다는 사실을 04~05 본문 완료로 세지 않는다. 첫 세 프로그램의 49개 런타임 CHECK와 팩 전체 221회 CHECK, 컴파일 시점 검사, 반복 실행 환경을 구분한다.

원본 팩은 C++20 기준이며 C++11 호환 팩이 아니다. C++11은 엄격한 컴파일 옵션에서 실제 거부되는지를 확인해 진단을 남긴다. 원본에 없는 C++11 이식판을 이번 배치에서 임의로 만들지 않는다. Windows/MSVC 실행 여부는 별도 표시한다.
