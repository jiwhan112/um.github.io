[심화 공통 팩](./shared/cpp-advanced-lab/README.md)의 원본 ZIP 44파일을 보존했지만, 그 안의 원본 프로그램 9개를 모두 새 교재로 세지 않는다. 첫 배치에서 설명하고 한국어 주석을 붙인 프로그램은 `lifetime`, `ownership`, `transaction` 3개다. 전체 원본의 검사 호출은 89회이고 첫 두 단원의 범위는 31회(10+13+8)이며, `Expect(true)` 도달 표시 1회와 컴파일 시점 검사도 구분한다. 여러 환경·주석판에서의 재실행을 독립 조건으로 더하지 않는다.

앞선 [심화 03~04 배치](./CPP_ADVANCED_03_04_20261021.md)는 상속·다형성과 연산자·템플릿 두 본문을 추가한다. 한국어 주석판은 `polymorphism`, `templates`, `interfaces`이며 검사 호출은 **29회(12+10+7)**, 별도의 `static_assert`는 4개다. 심화 01~04에서 연결하는 서로 다른 프로그램은 6개이고, 이들의 원본 검사 호출 합계는 **60회(31+29)**다. 원문 03의 실습 목록에는 `interfaces.cpp`도 있지만, 실제 NVI·Clone 구현은 `polymorphism.cpp`에 있다. `interfaces.cpp`의 연산자·단위·뷰는 04에서 설명하며 같은 7회 검사를 03에 다시 더하지 않는다.

이번 [심화 05~06 배치](./CPP_ADVANCED_05_06_20261021.md)는 컨테이너·반복자와 Pimpl·할당을 다룬다. 한국어 주석판은 `containers`, `allocation`, `pimpl` 세 프로그램이며 Pimpl의 헤더와 두 번역 단위를 포함한 5개 파일이다. 원본 검사 호출은 **29회(16+7+6)**, 별도의 `static_assert`는 1개다. 이제 심화 6개 본문이 원본 9개 프로그램의 **89회** 검사 호출을 모두 연결한다. 컨테이너의 비교자 비반사성 검사는 표본 3개이며 엄격 약순서 전체의 증명이 아니다. Pimpl의 현재 실험에는 할당 실패 주입·ABI·실제 재빌드 시간 측정이 없다.

심화 팩도 C++20 기준이다. C++11 엄격한 컴파일 거부는 호환 성공과 구분한다. ZIP 파일과 Markdown 코드 블록의 마지막 LF 한 개 차이는 수정하지 않고 무결성 원장에 기록했다. 본문·소스 복원, 새 실행, 공개 배포 상태는 배치 원장과 실제 Actions에서 별도 확인한다.

C++ 기초 5개와 심화 6개 다음에는 상위 목차의 기존 자료를 확인한다. 읽기 전용 조회에서 [C01 · C11 입력 검증·정수 범위와 C++11/20 교차 컴파일](https://app.notion.com/p/3fda99703f408153b1dffae9398aa3bc)을 확인했다. 기존 C 원본의 삭제 상태는 복원하지 않았으며 개정 본문·C01B·과거 로그는 별도 보존했다. 이전 후속 후보였던 [Effective C++ 기존 개정판의 6개 단원](https://app.notion.com/p/8178c17f593b4f4e83a0b42544b8fe2b)은 보류하고, 위 C 정규 과정 테스트 배치에 대한 피드백을 먼저 받는다. C 언어, Modern C++, Effective C++, Effective Modern C++은 위 상위 목차의 독립 트랙을 유지한다.
