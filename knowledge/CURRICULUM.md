## 현재 범위와 상태

기존 승인된 교재 개편과 예제 다운로드 보완은 완료했다. 기존 카탈로그의 **117개 문서**에는 본문과 별도 전체 소스 문서가 함께 포함된다. 이것은 장기 목차 전체를 모두 집필했다는 뜻이 아니다.

2026-10-26 요청에 따라 다음 **다섯 새 정규 과정**을 독립 집필한다. 기본 구성은 총 54단원이며, 주제의 정확한 경계와 실제 실험을 기준으로 단원을 구성한다. 문서 수를 맞추기 위한 빈 페이지는 만들지 않는다. **게임 엔진 개발과 Python·개발 도구 신규 과정은 이번 범위에서 제외**한다.

## 1. Modern C++ — 기능과 계약

C++ 기초·심화 이후 읽는다. 실제 예제의 표준 버전과 컴파일러를 명시한다. 최신 표준의 ISO 확정 여부, 작업 초안, 구현 지원은 서로 다른 사실이다.

1. 표준 버전·컴파일러·기능 검사와 이식성
2. auto·decltype·타입 추론
3. 초기화·nullptr·범위 있는 열거형
4. 값 범주·이동·noexcept
5. unique_ptr·shared_ptr·weak_ptr와 소유권
6. 람다·캡처·호출 객체
7. constexpr·컴파일 시간 계산·if constexpr
8. 가변 인자 템플릿·fold 표현식
9. string_view·span·빌린 데이터 수명
10. optional·variant·expected와 오류 표현
11. concepts·ranges와 지연 평가
12. jthread·stop_token·동시성, C++23 이후의 지원 경계

## 2. Effective Modern C++ — 설계 선택과 함정

Modern C++ 기능 설명을 전제로 설계 판단을 학습한다. Scott Meyers의 책은 주제 범위를 찾는 참고일 뿐이며, 지문·공식 예제·해설을 복제하지 않는다. 자체 게임 클라이언트 사례와 현재 표준의 차이를 구분한다.

1. 추론·auto를 선택하는 기준
2. 초기화·인터페이스·삭제 함수·override 계약
3. 스마트 포인터의 소유권 그래프
4. 이동·전달·참조 붕괴와 API 경계
5. 전달 참조 오버로드의 실패와 제약
6. 람다 캡처·비동기 콜백·수명
7. 작업 기반 동시성·atomic·future
8. Pimpl·통합 설계·측정과 비용 판단

## 3. DirectX 12 — 명시적 실행과 수명
