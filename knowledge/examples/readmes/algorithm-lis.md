# LIS 길이와 경로 복원 · 예제 다운로드

## 실행

압축을 풀고 C++11 이상을 지원하는 GCC/Clang으로 빌드합니다. 아래는 POSIX 셸 예시입니다.

```sh
cd project
c++ -std=c++11 -O0 -Wall -Wextra -Wpedantic -Werror main.cpp -o lis
./lis
```

stdin이나 파일 입력은 없습니다. 내부 고정 사례 12개와 시드 20261017의 생성 사례 1600개를 O(n²) 기준 구현과 비교합니다. 길이뿐 아니라 복원 인덱스의 범위·순서·엄격 증가를 검사합니다. 같은 값은 증가 수열을 연장하지 않습니다.

성공 출력은 `PASS AL03 LIS; checks=<검사 호출 수>`이고 종료 코드 0입니다. 난수 분포의 구현과 생성된 수열에 따라 검사 호출 수가 달라질 수 있어 숫자 하나를 플랫폼 공통 정답으로 고정하지 않습니다. 실패는 `FAIL AL03 ...`와 종료 코드 1입니다. 이 팩을 만들며 새 실행은 하지 않았습니다.
