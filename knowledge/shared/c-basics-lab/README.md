# C 기초 01–03 · 실행 검증

C11 기준으로 새로 작성한 한국어 주석 학습 코드다. Notion 원본을 복구하거나 이식한 소스가 아니다.

저장소를 받은 뒤 루트에서 실행한다:

```sh
python3 knowledge/shared/c-basics-lab/verify.py
```

GCC와 Python 3가 필요하다. 실행 결과는 이 폴더의 `verification.json`에 기록된다. `CC=clang`을 지정해 별도 재현할 수 있지만 현재 기록의 컴파일러와 혼동하지 않는다. 웹에서 파일만 내려받았다면 `knowledge/c-basics-01/main.c`부터 `03/main.c`까지, 이 폴더의 `verify.py`, `compile-error.c`, `link-error.c`를 같은 디렉터리 구조로 저장한다.

- 정상 프로그램 3개: 경고를 오류로 취급한 C11 빌드와 UBSan 빌드에서 각각 실행.
- 03의 실제 전체 코드를 입력·기대값만 바꿔 덧셈 경계 9조합 검사. 양수·음수 초과, 정확한 상하한, 0 포함.
- 01의 전처리·어셈블리 생성·객체 생성·링크를 나눠 실행하고 산출물 확인.
- 의도적인 문법 오류는 컴파일 실패, 정의 누락은 객체 생성 성공 후 링크 실패인지 확인.
- 모든 명령의 종료 코드·stdout·stderr와 원본 SHA-256을 기록. 여러 빌드의 반복 실행을 서로 다른 학습 문제로 세지 않는다.

`assert`를 사용하는 검증에서 `NDEBUG`는 정의하지 않는다. 현재 기록은 실제 GCC 호스트에 한정한다. Windows/MSVC·다른 CPU·모든 입력은 검증하지 않았다. UBSan 통과도 전체 안전성의 증명은 아니다. 웹 탭·그림·링크·모바일 줄넘침은 별도 React CI가 확인한다. GitHub Actions의 PR/배포 결과가 최종 웹 검증 근거다.
