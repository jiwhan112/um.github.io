배열과 문자열 1.1 — 중복 여부 판별

게일 라크만 맥도웰의 《코딩 인터뷰 완전 분석》(6판)의 장·주제 순서를 따릅니다. 여기의 연습 문제·테스트는 책 원문을 복제하지 않고 별도로 구성했습니다.

진도: 1장 / 1.1난이도: 기초언어: C++11힌트 → 풀이 → 복습

이번 회차의 문제

🔤 식별 문자열 검증

시스템에서 사용하는 식별 문자열은 영문 대문자 A~Z로만 구성됩니다. 문자열에 같은 문자가 두 번 이상 들어 있다면 false, 모든 문자가 한 번씩만 등장한다면 true를 반환하는 함수를 작성하세요.

예: ORBIT → true / LEVEL → false / "" → true

조건: 대소문자 구분 문제가 생기지 않도록 입력 범위를 대문자로 한정합니다. 먼저 어떤 자료구조를 쓸지 직접 생각해 보세요.

문제를 그림으로 나누기

직접 생각하기: 질문 3개

  1. 이중 반복문으로 모든 문자 쌍을 비교한다면 시간 복잡도는 얼마일까요?
  2. 알파벳이 26종류뿐이라는 조건을 이용하면 검사 횟수나 메모리를 줄일 수 있을까요?
  3. 문자열 길이가 27 이상이면 검사를 시작하기 전에 무엇을 알 수 있을까요?
힌트 1 · 중복 검사 아이디어

이전에 확인한 문자를 기억해 둔다면 새 문자를 처리할 때 이미 등장했는지 바로 확인할 수 있습니다.

힌트 2 · 자료구조 선택

입력 종류가 26개로 고정되어 있으니 bool seen[26]처럼 각 문자의 등장 여부를 기록하는 배열을 생각해 보세요.

힌트 3 · 비둘기집 원리

서로 다른 문자가 최대 26개라면 27글자 이상의 문자열에는 반드시 중복이 있습니다.

직접 작성해 보는 C++11 코드

답을 열기 전에 함수 본문을 작성해 보세요. 아래 메모는 현재 브라우저에만 저장되며 GitHub로 업로드되지 않습니다.

현재 브라우저에만 저장됩니다.
✅ 풀이 및 C++11 해설 펼치기

26개 문자의 등장 여부를 크기가 고정된 배열로 기억하면 됩니다. 현재 문자를 이미 봤다면 즉시 false를 반환합니다.

#include <array>
#include <string>

bool HasAllUniqueUppercase(const std::string& input) {
    if (input.size() > 26) {
        return false;
    }

    std::array<bool, 26> seen = {};
    for (char c : input) {
        const int index = c - 'A'; // 입력은 A~Z만 허용
        if (seen[index]) {
            return false;
        }
        seen[index] = true;
    }
    return true;
}

시간: 문자열 길이를 n이라 하면 O(n), 단 위 코드의 길이 제한 때문에 실제 순회는 최대 26회입니다. 공간: O(1) — 알파벳 개수가 고정이기 때문입니다.

범위를 벗어난 문자에 대해서는 이 함수가 정의되지 않은 인덱스에 접근할 수 있습니다. 실제 제품 코드에서는 입력을 검증하거나 허용 문자 정책을 명확히 해야 합니다.
